# Extension Icons

Please add PNG icons for the extension:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

You can create these icons using any design tool. They should represent the Soniox Meet Transcription extension.

For now, the extension will show a default icon in Chrome if these files are missing.
